# Week 1 - Prompt Basics (Zero-Shot vs Few-Shot)

## Objective

The purpose of this task is to compare Zero-Shot and Few-Shot prompting techniques using Large Language Models (LLMs).

The task involves classifying customer support messages into three categories:

- Complaint
- Question
- Praise

The prompts were tested on:

- ChatGPT
- Claude
- Gemini

Repository contains:

- prompts
- outputs
- comparison
- reflection
